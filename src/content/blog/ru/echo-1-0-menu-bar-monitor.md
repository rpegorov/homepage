Echo — нативное приложение для строки меню macOS. Системные метрики и несколько повседневных утилит в одном значке.

## Что внутри

**Мониторинг.** По клику на значок открывается окно с тремя кольцами — процессор, память, диск — и текущей скоростью сети. У каждой метрики есть подробное окно: график, самые тяжёлые процессы по процессору, самые прожорливые по памяти и самые большие файлы на диске. Любой файл из списка можно сразу показать в Finder.

**Менеджер окон.** Половины, четверти, развернуть и центрировать — по горячим клавишам ⌃⌘ со стрелками и буквами. Окно можно дотащить до края или угла экрана, и оно встанет туда само. Зажатый Shift отменяет прилипание.

**История буфера обмена.** Последние скопированные тексты, картинки и файлы, по ⌘⇧V. Пароли и временные записи из менеджеров паролей в историю не попадают. Всё хранится только в памяти.

**Утилиты.**

- **Keyboard Cleaning** — блокирует клавиатуру, пока её протираешь.
- **Prevent Sleep** — не даёт Mac уснуть.
- **Очистка диска** через консольную утилиту [mole](https://github.com/tw93/mole).

## Бережёт батарею

Пока окна Echo закрыты, метрики не опрашиваются. Во время сна системы опрос останавливается, в режиме энергосбережения — замедляется. Всё это настраивается. Интервал обновления — от 0,5 до 5 секунд.

## Что не делает

Echo работает только на вашем Mac. Нет аккаунтов, телеметрии и сетевых запросов для своих нужд: метрики и буфер обмена никуда не уходят.

## Как поставить

Нужна macOS 26.1 или новее. Скачайте `Echo-1.0.dmg` со [страницы релизов](https://github.com/rpegorov/Echo/releases) и перетащите Echo.app в «Программы». Сборка не нотаризована, поэтому первый запуск — правый клик по Echo.app → Open → Open. Для менеджера окон нужен доступ в System Settings → Privacy & Security → Accessibility.
